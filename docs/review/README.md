## 这些审查共同遵守的规矩

没有运行时证据的不写成缺陷。每一条都要先写一个探针让它真的出错（红），再改，
再跑同一个探针确认变绿，最后把"缺陷的修复"和"证明它的东西"分成两次提交。这个
规矩从第一轮到第八轮没有变过，也是这些报告里最值得看的部分——比结论本身更值得。
